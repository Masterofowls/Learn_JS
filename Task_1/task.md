
Блок 1. Типы данных и typeof

Задание 1 (Лёгкое)
Объявите 5 переменных с разными типами: строку, число, логическое, null и undefined. Выведите в консоль тип каждой переменной через typeof.

Задание 2 (Среднее)
Что выведет этот код и почему?

```JavaScript
console.log(typeof null);
console.log(typeof []);
console.log(typeof 42 / 0);
```

Задание 3 (Среднее)
Даны переменные:

```JavaScript
let a = '100';
let b = 100;
let c = true;
```

Используя typeof, проверьте:

· Является ли a строкой?
· Является ли b числом?
· Является ли c логическим типом?
  Выведите в консоль true или false для каждого сравнения.

Блок 3. Условный оператор (if / else)

Задание 7 (Лёгкое)
Дана переменная age = 25. Напишите код, который проверяет:

· Если age меньше 18 — выведите 'Доступ запрещён'
· Если age от 18 до 60 включительно — 'Доступ разрешён'
· Если age больше 60 — 'Вам скидка!'

Задание 8 (Среднее)
Даны три числа: x = 10, y = 25, z = 15. Найдите наибольшее из них, используя только if и else (без Math.max). Выведите результат в консоль.

Задание 9 (Среднее)
Дана переменная password = 'qwerty'. Напишите проверку:

· Если пароль пустой ('') — выведите 'Пароль не может быть пустым'
· Если длина меньше 6 — 'Слишком короткий'
· Если длина >= 6 и содержит символ '!' — 'Надёжный пароль'
· Иначе — 'Слабый пароль'
  (Для проверки наличия ! используйте метод includes().)

Блок 4. Тернарный оператор

Задание 10 (Лёгкое)
Перепишите этот if в тернарный оператор:

```JavaScript
let age = 20;
let message;
if (age >= 18) {
  message = 'Совершеннолетний';
} else {
  message = 'Несовершеннолетний';
}
console.log(message);
```

Блок 5. Switch

Задание 13 (Лёгкое)
Дана переменная day = 'ср'. Напишите switch, который для названий дней 'пн', 'вт', 'ср', 'чт', 'пт' выводит 'Рабочий день', а для 'сб', 'вс' — 'Выходной'. Если день не из списка — 'Некорректный день'.

Задание 14 (Среднее)
Перепишите этот if-else в switch:

```JavaScript
const color = 'red';
if (color === 'red') {
  console.log('Стоп');
} else if (color === 'yellow') {
  console.log('Внимание');
} else if (color === 'green') {
  console.log('Идите');
} else {
  console.log('Неизвестный сигнал');
}
```
