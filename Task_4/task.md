1. Дескрипторы свойств объекта (Property Descriptors)

Задача 1.1 (Конфигурация)
Создайте объект user с именем "Alex". Сделайте так, чтобы это свойство было доступно только для чтения (нельзя перезаписать), но при этом его можно было удалить (delete).

Задача 1.2 (Счетчик с защитой)
Создайте объект counter с числовым свойством value.
Используя дескриптор, сделайте так, чтобы при попытке записать в value отрицательное число или строку, операция игнорировалась (или выбрасывала ошибку), а само свойство было неперечислимым (enumerable: false).

Задача 1.3 (Геттер/сеттер VS дескриптор)
Напишите функцию makeObservable(obj), которая с помощью Object.defineProperty добавляет всем существующим свойствам объекта геттеры и сеттеры, логирующие в консоль сообщение: "Читаем свойство X" или "Записываем Y в свойство X".

2. Привязка контекста (bind, call, apply)

Задача 2.1 (Потеря this)
Дан объект:

const timer = {
  seconds: 0,
  start() {
    setInterval(function() {
      this.seconds++;
      console.log(this.seconds);
    }, 1000);
  }
};
Исправьте код, не меняя структуру вложенной функции, чтобы this ссылался на объект timer. (Использовать bind).

Задача 2.2 (Калькулятор с call/apply)
Напишите функцию sum(a, b), которая возвращает сумму.
Создайте объект context = { multiplier: 2 }.
Используя call и apply, вызовите функцию так, чтобы она вернула не просто сумму, а сумму, умноженную на this.multiplier. Подсказка: функция должна брать множитель из контекста.

Задача 2.3 (Каррирование с bind)
Напишите функцию multiply(a, b). Используя bind, создайте новую функцию double, которая всегда умножает переданное число на 2. Вызовите double(5) (должно вернуть 10).

Задача 2.4 (Универсальный бордер)
Есть функция format(prefix, suffix, text), которая возвращает prefix + text + suffix.
Используя bind, создайте функцию addBrackets(text), которая добавляет к тексту квадратные скобки [ и ], не создавая новые глобальные переменные для префикса и суффикса.

3. Классы (Class Syntax)

Задача 3.1 (Базовый класс)
Создайте класс Animal с конструктором, принимающим name.
Добавьте метод speak(), который выводит в консоль: "${this.name} издает звук".

Задача 3.2 (Статический метод)
Добавьте в класс Animal статический метод compare(animalA, animalB), который возвращает true, если имена животных совпадают, и false в противном случае. Вызовите его без создания экземпляра.

Задача 3.3 (Проверка instanceof)
Создайте класс Car с полем brand. Создайте его экземпляр. Напишите функцию, которая проверяет, является ли переданный объект экземпляром Car, и если да — выводит марку, иначе выводит "Не машина".

4. Защищённые свойства. Геттеры и Сеттеры (Getters/Setters)

Задача 4.1 (Валидация возраста)
Создайте класс User с приватным полем _age.
Через сеттер age сделайте проверку: если присваиваемое значение меньше 0, выбрасывайте ошибку "Age cannot be negative". Если больше 150 — выбрасывайте ошибку "Age is too high".
Геттер age должен просто возвращать значение.

Задача 4.2 (Вычисляемое свойство)
Создайте класс Rectangle с сеттерами для width и height.
Добавьте геттер area, который возвращает площадь (ширина * высота). Убедитесь, что при изменении ширины, площадь пересчитывается автоматически (без отдельного метода update).

Задача 4.3 (Скрытый пароль)
Создайте класс Account с приватным полем #password (используйте современный синтаксис приватных полей).
Сделайте сеттер password, который хеширует переданный пароль (просто добавьте строку "_hash" в конце) и сохраняет в #password.
Сделайте геттер, который возвращает "****" (звездочки), чтобы настоящий пароль нельзя было прочитать.

5. Наследование классов (Inheritance)

Задача 5.1 (Базовое наследование)
Создайте класс Dog, который наследуется от Animal (из задачи 3.1).
Переопределите метод speak(), чтобы он выводил "${this.name} лает".
В конструкторе Dog добавьте параметр breed и передайте name в родительский класс через super().

Задача 5.2 (Цепочка конструкторов)
Создайте класс Vehicle (транспорт) с полями wheels и speed.
Создайте класс Bicycle, наследующий Vehicle. Конструктор Bicycle должен принимать speed и автоматически устанавливать wheels = 2. Добавьте в Bicycle метод ringBell().

Задача 5.3 (Расширение методов)
Создайте класс ArrayExtended, который наследует встроенный Array.
Добавьте метод last(), который возвращает последний элемент массива (не удаляя его).
Добавьте метод sum(), который возвращает сумму всех элементов (предполагаем, что элементы — числа).
Пример: new ArrayExtended(1, 2, 3).last() → 3, .sum() → 6.

Задача 5.4 (Миксин поведения)
Создайте два класса: Flyable (с методом fly()) и Swimmable (с методом swim()).
Создайте класс Duck, который должен наследовать поведение обоих (имитация множественного наследования через функции-примеси или композицию). Реализуйте это без использования сторонних библиотек.

"Прокси-валидатор"

Переопределите сеттер age так, чтобы:

2. Создайте статический метод createAdult(name, age), который возвращает нового пользователя, но если возраст < 18, автоматически устанавливает возраст = 18.

Используйте дескрипторы, чтобы сделать свойство name защищенным от перезаписи после создания объекта
